# App Launcher tiles

Logos for the Cloudflare Access App Launcher: 512×512 rounded squares on `#0f172a`, so the tiles
line up. Link them by raw URL, e.g.
`https://raw.githubusercontent.com/ThinkHumanDotDev/.github/main/assets/app-launcher/portainer.svg`.

| File | Source |
| --- | --- |
| `portainer.svg` | ThinkHuman's "P" mark on the shared tile |
| `zohomail.svg` | Zoho Mail mark from [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons), blue lightened to `#4a9ae8` for contrast |
| `webssh.svg` | unchanged from [selfhst/icons](https://github.com/selfhst/icons) |
