# Getting help

| You want to | Go to |
| --- | --- |
| Report a bug or ask for a change | the repository's Issues tab, using a template |
| Ask a question or discuss an idea | the repository's Discussions, where they are on, otherwise an issue |
| Report a security vulnerability | a private security advisory or security@thinkhuman.dev, see [SECURITY.md](SECURITY.md) |
| Report conduct | conduct@thinkhuman.dev, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Search existing issues first. Say what you ran, what you expected and what happened, with the
version or commit and any logs, secrets removed.
